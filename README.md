# Portal o muzyce (React + Vite)

Mini-portal w Reactcie w stylu Spotify.

## Uruchomienie lokalnie
```
npm install
npm run dev
```

## Dodawanie utworów
Otwórz `src/main.jsx` i uzupełnij tablicę `listaUtworow`:
```
["Tytuł utworu", "Krótki opis"],
```

## Publikacja online (GitHub Pages)
1. `npm run build`
2. Zawartość folderu `dist` wrzuć na gałąź `gh-pages` albo użyj Netlify / Vercel
   (komenda budowania: `npm run build`, folder publikacji: `dist`).
